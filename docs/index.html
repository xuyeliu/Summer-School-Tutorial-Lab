Privacy Lab: Membership Inference and DP-SGD

Attack a model to tell whether a patient's X-ray was in its training set, then defend it with differentially private training.

Open the lab in Google Colab No install needed, runs in your browser
  1. Pick a GPU: Runtime > Change runtime type > T4 GPU. CPU works but Phase 3a is slow. TPU is not supported, because Opacus needs PyTorch per-sample gradients.
  2. Run the setup cell at the top. It downloads the pre-trained checkpoints that Phase 4 needs.
  3. To keep your work, choose File > Save a copy in Drive. The lab opens read-only from GitHub, so without a copy your edits disappear when the tab closes.
